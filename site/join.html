A panel next to the League client that suggests picks, bans and builds from your own games and the meta in your rank. Four steps, about five minutes.

Your invite code (works once)

This link has no invite code. Ask the person who invited you to send the link again.

  1. Download

    The installer for Windows 10 or 11.

    Download for Windows From GitHub Releases.

  2. Install

    Run the file. Windows says "Windows protected your PC" because the app isn't code-signed: click More info, then Run anyway, and finish the installer.

  3. Open League and log in

    The app reads your Riot ID from the client, so you never type it. Log in before the next step.

  4. Open the app with your code

    The button opens LoL Draft Coach with your code filled in: click Connect there. If your browser asks, allow it to open the app.
